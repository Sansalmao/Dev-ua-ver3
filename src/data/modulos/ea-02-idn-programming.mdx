## Implementing IDNA2008 - Java

<span class="hl">Commonly used IDNA2008 libraries in Java</span>

- Since the `java.net.IDN` class lacks IDNA2008 support, employing third-party libraries is essential for encoding and decoding IDNs in Java.
- You can achieve IDNA2008 support in Java using the **ICU4J** library.
  - Download and import the ICU4J library: Obtain the ICU4J library JAR file from the official ICU project website or a trusted source. Add the JAR file to your Java project's classpath.

### IDNA2008 Library Usage in Java — Encoding

<span class="hl">Example: IDNA2008 library usage in Java — Encoding:</span> The domain `تجربة-القبول-الشامل.موريتانيا` means "universal acceptance test" in Arabic and uses the `.موريتانيا` (Mauritania) ccTLD.

<div class="code-switcher">
  <div class="lang-switcher">
    <button class="lang-btn active" data-lang="java" data-target="enc1"><span class="lang-icon lang-icon--java"></span>Java</button>
  </div>
  <div class="lang-block active" data-lang="java" data-group="enc1">

```java
// Encoding IDN to Punycode
import com.ibm.icu.text.IDNA;
import com.ibm.icu.text.IDNA.Info;

public class IDNAExample {
    public static void main(String[] args) {
        String unicodeDomainName = "تجربة-القبول-الشامل.موريتانيا";
        // Create an IDNA converter
        IDNA idna = IDNA.getUTS46Instance(IDNA.DEFAULT);
        try {
            // Convert Unicode to ASCII (Punycode)
            StringBuilder punycodeDomainNameBuilder = new StringBuilder();
            idna.nameToASCII(unicodeDomainName, punycodeDomainNameBuilder, new Info());
            String punycodeDomainName = punycodeDomainNameBuilder.toString();
            System.out.println("Punycode: " + punycodeDomainName);
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
// Output: xn-----ctdbabcfhu9c2b9l1acccr4c.xn--mgbah1a3hjkrd
```

<span class="hl">Commonly used IDNA2008 libraries in Python</span>

<span class="hl">Example: IDNA2008 library usage in Python:</span>

## Pitfalls of IDNA2003 Libraries and Remediation in IDNA 2008 - Java

<span class="hl">IDNA2003 Libraries — Limited Character Set Support</span>

The domain `straße.de` (German for "street.de") exposes a key difference: IDNA2003 (`java.net.IDN`) maps `ß` to `ss`, losing the original character. IDNA2008 (ICU4J) preserves it correctly via Punycode.

<div class="code-switcher">
  <div class="lang-switcher">
    <button class="lang-btn active" data-lang="java-2003" data-target="pitfall1"><span class="lang-icon lang-icon--java"></span>Java (IDNA2003)</button>
    <button class="lang-btn" data-lang="java-2008" data-target="pitfall1"><span class="lang-icon lang-icon--java"></span>Java (IDNA2008)</button>
  </div>
  <div class="lang-block active" data-lang="java-2003" data-group="pitfall1">

```java
import java.net.IDN;

public class IDNACharacterSet {
    public static void idna2003Support() {
        String unicodeDomainName = "straße.de";
        try {
            // Convert Unicode domain name to Punycode using IDNA2003
            String punycodeDomainNameIDNA2003 = IDN.toASCII(unicodeDomainName);
            System.out.println("Punycode domain name (IDNA2003): " + punycodeDomainNameIDNA2003);
            // Attempt to convert Punycode domain name back to Unicode using IDNA2003
            String decodedDomainNameIDNA2003 = IDN.toUnicode(punycodeDomainNameIDNA2003);
            System.out.println("Decoded domain name (IDNA2003): " + decodedDomainNameIDNA2003);
        } catch (IllegalArgumentException e) {
            System.out.println("Error (IDNA2003): " + e.getMessage());
        }
    }

    public static void main(String[] args) {
        System.out.println("Demonstrating IDNA2003 Support:");
        idna2003Support();
    }
}
```

  <div class="lang-block" data-lang="java-2008" data-group="pitfall1">

## Pitfalls of IDNA2003 Libraries and Remediation in IDNA 2008 - Python

<span class="hl">IDNA2003 Libraries: Limited Character Set Support</span>

The domain `straße.de` exposes a key difference between IDNA2003 and IDNA2008 in Python: the built-in `encodings.idna` module (IDNA2003) maps `ß` to `ss`, while the `idna` library (IDNA2008) preserves it correctly via Punycode.

<div class="code-switcher">
  <div class="lang-switcher">
    <button class="lang-btn active" data-lang="python-2003" data-target="pitfall2"><span class="lang-icon lang-icon--python"></span>Python (IDNA2003)</button>
    <button class="lang-btn" data-lang="python-2008" data-target="pitfall2"><span class="lang-icon lang-icon--python"></span>Python (IDNA2008)</button>
  </div>
  <div class="lang-block active" data-lang="python-2003" data-group="pitfall2">

```python
import encodings.idna

def idna2003_support():
    unicode_domain_name = "straße.de"
    try:
        # Convert Unicode domain name to Punycode using IDNA2003
        punycode_domain_name_idna2003 = encodings.idna.ToASCII(unicode_domain_name)
        print("Punycode domain name (IDNA2003):", punycode_domain_name_idna2003)
        # Convert Punycode domain name back to Unicode using IDNA2003
        decoded_domain_name_idna2003 = encodings.idna.ToUnicode(punycode_domain_name_idna2003)
        print("Decoded domain name (IDNA2003):", decoded_domain_name_idna2003)
    except UnicodeError as e:
        print("Error (IDNA2003):", str(e))

if __name__ == "__main__":
    print("Demonstrating IDNA2003 Support:")
    idna2003_support()
```

## IDNA2003 Security Vulnerabilities — Homograph Attack

<span class="hl">Example: Explaining IDNA2003 Security Vulnerabilities — Homograph Attack</span>

In a homograph attack, visually similar characters from different scripts (e.g., Latin `o` vs. Cyrillic `о`) are used to craft deceptive domain names. IDNA2003 silently allows mixed-script labels, while IDNA2008 raises an error.

<div class="code-switcher">
  <div class="lang-switcher">
    <button class="lang-btn active" data-lang="java" data-target="homo1"><span class="lang-icon lang-icon--java"></span>Java</button>
    <button class="lang-btn" data-lang="python" data-target="homo1"><span class="lang-icon lang-icon--python"></span>Python</button>
  </div>
  <div class="lang-block active" data-lang="java" data-group="homo1">

```java
import java.net.IDN;
import com.ibm.icu.text.IDNA;

public class IDNAHomographAttackExample {
    // IDNA2003: allows mixed-script label silently
    public static void demonstrateIDNA2003HomographAttack() {
        String unicodeDomainNameHomograph = "example.cоm"; // Cyrillic 'о' (U+043E)
        try {
            String punycodeDomainNameIDNA2003 = IDN.toASCII(unicodeDomainNameHomograph);
            System.out.println("Punycode domain name (IDNA2003): " + punycodeDomainNameIDNA2003);
        } catch (IllegalArgumentException e) {
            System.out.println("Error (IDNA2003): " + e.getMessage());
        }
    }

    // IDNA2008: raises an error on mixed-script labels
    public static void demonstrateIDNA2008HomographAttackPrevention() {
        String unicodeDomainNameHomograph = "example.cоm"; // Cyrillic 'о' (U+043E)
        IDNA idna = IDNA.getUTS46Instance(IDNA.CHECK_BIDI | IDNA.CHECK_CONTEXTJ);
        StringBuilder result = new StringBuilder();
        IDNA.Info info = new IDNA.Info();
        idna.nameToASCII(unicodeDomainNameHomograph, result, info);
        if (info.hasErrors()) {
            System.out.println("Error (IDNA2008): Mixed-script label detected — " + info.getErrors());
        } else {
            System.out.println("Punycode domain name (IDNA2008): " + result.toString());
        }
    }

    public static void main(String[] args) {
        System.out.println("IDNA2003 Homograph Attack:");
        demonstrateIDNA2003HomographAttack();
        System.out.println("\nIDNA2008 Homograph Attack Prevention:");
        demonstrateIDNA2008HomographAttackPrevention();
    }
}
```

  </div>
  <div class="lang-block" data-lang="python" data-group="homo1">

## IDNA2003 Deficiency in Enforcing Contextual Rules for Characters

<span class="hl">IDNA2003 vs. IDNA2008 — Hyphen Handling at Label Boundaries</span>

IDNA2003 does not enforce all contextual rules, such as disallowing hyphens at the beginning or end of a label. IDNA2008 correctly rejects these invalid forms.

<div class="code-switcher">
  <div class="lang-switcher">
    <button class="lang-btn active" data-lang="python" data-target="ctx1"><span class="lang-icon lang-icon--python"></span>Python</button>
  </div>
  <div class="lang-block active" data-lang="python" data-group="ctx1">

```python
from idna import encode

def demonstrate_idna2003_vs_idna2008_hyphen_handling():
    # Hyphen at the beginning of the label
    domain_name_hyphen_beginning = "-example.com"
    try:
        # Convert using IDNA2003 (built-in codec)
        punycode_domain_name_idna2003 = domain_name_hyphen_beginning.encode('idna').decode('utf-8')
        print("Punycode domain name (IDNA2003):", punycode_domain_name_idna2003)
    except UnicodeError as e:
        print("Error (IDNA2003):", str(e))
    try:
        # Convert using IDNA2008
        punycode_domain_name_idna2008 = encode(domain_name_hyphen_beginning)
        print("Punycode domain name (IDNA2008):", punycode_domain_name_idna2008)
    except UnicodeError as e:
        print("Error (IDNA2008):", str(e))

if __name__ == "__main__":
    print("Demonstrating IDNA2003 vs. IDNA2008 Hyphen Handling:")
    demonstrate_idna2003_vs_idna2008_hyphen_handling()
```

  </div>
</div>

<div class="obs-card">

<span class="hl">Key takeaway for instructors:</span> IDNA2008 strictly enforces contextual rules defined in RFC 5891 — including prohibitions on hyphens in the third and fourth positions (reserved for `xn--` Punycode prefix) and at label boundaries. This prevents malformed domain names that IDNA2003 would silently accept.

## Parsing the tlds-alpha-by-domain.txt File

<span class="hl">Parsing the IANA `tlds-alpha-by-domain.txt` file to extract active IDN TLDs</span>

The IANA publishes a list of all active TLDs. IDN TLDs are encoded in Punycode and always begin with `XN--`. The examples below download this list and extract only the IDN TLDs.

<div class="code-switcher">
  <div class="lang-switcher">
    <button class="lang-btn active" data-lang="java" data-target="tld1"><span class="lang-icon lang-icon--java"></span>Java</button>
    <button class="lang-btn" data-lang="python" data-target="tld1"><span class="lang-icon lang-icon--python"></span>Python</button>
  </div>
  <div class="lang-block active" data-lang="java" data-group="tld1">

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.net.HttpURLConnection;
import java.net.URL;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

public class IDNParserExample {
    public static void main(String[] args) {
        String url = "https://data.iana.org/TLD/tlds-alpha-by-domain.txt";
        try {
            URL obj = new URL(url);
            HttpURLConnection con = (HttpURLConnection) obj.openConnection();
            con.setRequestMethod("GET");
            int responseCode = con.getResponseCode();
            if (responseCode == HttpURLConnection.HTTP_OK) {
                BufferedReader in = new BufferedReader(
                    new InputStreamReader(con.getInputStream()));
                String inputLine;
                StringBuilder content = new StringBuilder();
                while ((inputLine = in.readLine()) != null) {
                    content.append(inputLine);
                    content.append(System.lineSeparator());
                }
                in.close();
                // Extract IDN TLDs starting with XN--
                String pattern = "XN--[A-Z0-9\\-]+";
                Matcher matcher = Pattern.compile(pattern).matcher(content.toString());
                while (matcher.find()) {
                    System.out.println(matcher.group());
                }
            } else {
                System.out.println("Failed to retrieve data. Status code: " + responseCode);
            }
        } catch (IOException e) {
            System.out.println("An error occurred: " + e.getMessage());
        }
    }
}
```

  </div>
  <div class="lang-block" data-lang="python" data-group="tld1">

```python
import requests
import re

# Download the IDN TLDs list
url = "https://data.iana.org/TLD/tlds-alpha-by-domain.txt"
try:
    response = requests.get(url)
    if response.status_code == 200:
        content = response.text
        # Extract IDN TLDs starting with XN--
        idn_tlds = re.findall(r"XN--[A-Z0-9\-]+", content)
        for tld in idn_tlds:
            print(tld)
    else:
        print(f"Failed to retrieve data. Status code: {response.status_code}")
except requests.exceptions.RequestException as e:
    print(f"An error occurred: {e}")
```
